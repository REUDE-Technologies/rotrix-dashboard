### Slide 22: Project Track 1 - Drone Systems

**Slide title:** Drone Systems Integration & Development

**Project scope:**  
ZD850 with Raspberry Pi, cameras, S500 drone, Marut drone, and REUDE’s own drone design.

**Suitable for:**  
Design, mechanical, electronics, embedded, software, and drone-enthusiast students.

**Objective:**

- To study, integrate, test, and improve different drone platforms used for REUDE’s UAV development and application testing.
- To help interns understand drone structure, onboard electronics, flight systems, camera integration, payload considerations, and field-readiness.
- To involve design students in understanding frame layout, payload positioning, mounting, enclosure design, and system packaging.

**Intern tasks:**

- Study the hardware layout of ZD850, S500, Marut drone, and REUDE’s custom drone design.
- Identify components: frame, flight controller, Raspberry Pi, cameras, ESCs, motors, GPS, telemetry, batteries, and payload interfaces.
- Document system architecture for each drone platform.
- Assist in camera/Raspberry Pi mounting, cable routing, and payload placement.
- Support basic integration checks and pre-flight inspection documentation.
- Compare drone platforms based on payload capacity, stability, use case, and modification flexibility.
- For design students: create or improve mounting brackets, enclosures, payload holders, or structural layout ideas.

**Learning outcomes:**

- Drone platform architecture and component-level understanding.
- Basics of UAV integration, payload placement, and field testing.
- Practical exposure to Raspberry Pi, cameras, flight hardware, and drone subsystems.
- Design thinking for real UAV packaging and payload support.

**Picture to use:**

### Slide 23: Project Track 2 - Grabber Arm Payload Detection

**Slide title:** Grabber Arm Payload Detection

**Project scope:**  
Payload detection and validation for REUDE’s grabber arm system using electronics, PCB-level understanding, sensing, and AI/ML support.

**Suitable for:**  
Design, electronics, embedded systems, and AI/ML students.

**Objective:**

- To develop and validate a payload detection system for the grabber arm mechanism.
- To help the system understand whether a payload is present, locked, released, or improperly held.
- To support safer and smarter payload handling in drone-based delivery, logistics, and field operations.

**Intern tasks:**

- Study the grabber arm mechanism and understand payload lock/release behavior.
- Review PCB images and identify key electronic sections such as sensor inputs, connectors, controller area, and power lines.
- Explore suitable payload detection methods: limit switch, proximity sensor, load sensor, camera-based detection, or combined sensing.
- Document signal flow from sensor/PCB to controller/software.
- Assist in preparing test cases for payload present, payload absent, partial lock, and release condition.
- For AI/ML students: explore image-based or sensor-data-based detection logic for payload confirmation.
- For design students: suggest mechanical improvements for sensor placement, mounting, and payload alignment.

**Learning outcomes:**

- Understanding of sensor-based payload detection.
- Exposure to PCB inspection, signal flow, and embedded input handling.
- Basics of robotic gripper/grabber validation.
- Practical understanding of how mechanical, electronics, and AI systems combine in payload automation.

**Picture to use:**  
Use the available PCB images and grabber arm image. Best layout: grabber arm on one side, PCB/sensor images on the other side, with arrows showing detection flow.

**Presenter note:**  
Explain this as a cross-domain project. It is not only mechanical or electronics: it combines sensing, control logic, validation, and possible AI-based detection.

### Slide 24: Project Track 3 - Obstacle Avoidance with Stereo Vision

**Slide title:** Obstacle Avoidance Using Stereo Vision

**Project scope:**  
Stereo-camera-based depth perception and obstacle detection for drone navigation support.

**Suitable for:**  
Electronics, software, AI/ML, and computer vision students.

**Objective:**

- To explore stereo vision as a method for detecting obstacles around a drone or robotic platform.
- To estimate depth/distance using two-camera input and support safer navigation decisions.
- To build a foundation for autonomous obstacle-aware drone movement.

**Intern tasks:**

- Study the concept of stereo vision and depth estimation.
- Understand stereo camera setup, calibration, baseline distance, and image alignment.
- Capture sample stereo image/video data in controlled environments.
- Explore depth map generation using computer vision methods.
- Identify obstacles from image/depth data and estimate approximate distance.
- Test different lighting, distance, and obstacle conditions.
- Document limitations such as low light, reflective surfaces, motion blur, and calibration errors.

**Learning outcomes:**

- Basics of computer vision and stereo depth estimation.
- Camera calibration and image processing workflow.
- Practical understanding of obstacle detection challenges.
- Exposure to AI/ML-assisted perception for autonomous drones.

**Picture to use:**  
Use a stereo camera image, sample depth map, or drone with camera module. Best layout: **Left image + right image → depth map → obstacle warning**.

**Presenter note:**  
Keep the explanation simple: two cameras help estimate distance like human eyes. This project gives interns a strong entry into drone perception and autonomy.

### Slide 25: Project Track 4 - GPS-Denied Navigation Using Visual Inertial Odometry

**Slide title:** GPS-Denied Navigation Using Visual Inertial Odometry

**Project scope:**  
Navigation support when GPS is unavailable or unreliable, using camera input and inertial sensor data.

**Suitable for:**  
Electronics, embedded systems, software, robotics, and AI/ML students.

**Objective:**

- To study and prototype navigation methods for environments where GPS signals are weak, blocked, or unavailable.
- To combine camera-based visual tracking with IMU data for estimating motion and position.
- To support future autonomous drone operation in indoor, urban, defence, or obstructed environments.

**Intern tasks:**

- Study GPS-denied navigation problems and why they matter for drones.
- Understand Visual Odometry, IMU data, and Visual Inertial Odometry basics.
- Explore camera + IMU sensor setup and data logging.
- Test motion tracking using sample video or real sensor data.
- Compare estimated movement with actual movement in a controlled environment.
- Document drift, sensor noise, lighting issues, and calibration needs.
- Prepare a basic workflow diagram for GPS-denied navigation architecture.

**Learning outcomes:**

- Understanding of drone navigation beyond GPS.
- Basics of visual odometry, IMU sensing, and sensor fusion.
- Exposure to robotics navigation concepts used in autonomous systems.
- Practical understanding of data logging, testing, and error analysis.

**Picture to use:**  
Use a diagram showing **camera + IMU → motion estimation → navigation path**. A drone in an indoor/urban environment can be used as the background.

**Presenter note:**  
Explain this as an advanced autonomy project. It is suitable for students interested in robotics, navigation, perception, and drone intelligence.
